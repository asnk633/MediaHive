More Than A Task Manager

MediaHive was built around the way real media departments operate—not the way generic project management software thinks they should.

📋

Offline-First Task Management

Keep working under any conditions. Changes are cached locally in IndexedDB/Dexie and optimistically synced when connection returns, using a seamless Last-Write-Wins (LWW) resolution engine with server-merge fallback warnings.

📁

Google Drive Proxy

Stream high-res footage and assets directly through a secure Vercel API proxy. Bypasses CORS and protects service credentials entirely on the server.

👥

NFC & Presence Tracking

Verify on-site presence using mobile NFC scan terminals and battery-adaptive background geofencing heartbeats for total crew accountability.

📅

Real-time Event Operations

Coordinate shoots, broadcasts, and gear bookings. Prevents editing conflicts across devices using a real-time Server-Sent Events (SSE) Ghost Edit-Locking registry that instantly flags active editors.

📊

Role-Based Analytics & Reports

De-risk project governance. Get secure, role-restricted manager dashboards tracking crew velocity, department-wide bottlenecks, and automatic presence timesheet CSV exports.

🔔

Smart SSE Streams

Cut the slack. Get real-time event updates via lightweight Server-Sent Events (SSE) subscriptions, with low-latency Expo mobile push notification routing.

🖥️

Native Desktop Integration

A premium Tauri-wrapped Windows experience with system tray minimize-to-tray lifecycle, global hotkeys, background autostart, and signed OTA updates.
