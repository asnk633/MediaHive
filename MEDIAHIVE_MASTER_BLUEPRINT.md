## 3. Critical Constraints & Workarounds

### 🔒 Capacitor `/api/` Relative Path Constraint
* **Context**: Capacitor mobile packages are served from `localhost` / `capacitor://localhost`. Relative fetches like `/api/tasks` default to local device storage and fail.
* **Workaround**: Every API request must pass through the `apiClient` wrapper, which dynamically prepends the correct absolute backend base URL (e.g. `https://thaiba-garden-media-manager.vercel.app`).
* **Linter Rule**: The ESLint custom rule `no-restricted-syntax` bans all direct `/api/` string and template literals.
* **Workaround Syntax**: To pass the static linter check without string concatenation obfuscation:
  * Import `API_BASE` from `@/lib/api-utils` (defined as `'/api'` without a trailing slash, which does not trigger the literal matcher).
  * Use template literals: `apiClient(`${API_BASE}/endpoint`)` or `apiClient(`${API_BASE}/endpoint/${id}`)`

### 🔑 Access Token Refresh (Direct REST APIs)
* **Context**: Direct REST endpoints called via `http` or `dio` in mobile (e.g. offline sync, chat, upload) read `accessToken` directly from `currentSession` without checking for expiration. Since these bypass the Supabase client wrapper, they fail with `401/403` once the token expires (typically after 1 hour).
* **Workaround**: Future modifications must route requests through a token refresh wrapper that calls `await Supabase.instance.client.auth.refreshSession()` if the current session is expired.

## 3. Critical Constraints & Workarounds

### 🔒 Capacitor `/api/` Relative Path Constraint
* **Context**: Capacitor mobile packages are served from `localhost` / `capacitor://localhost`. Relative fetches like `/api/tasks` default to local device storage and fail.
* **Workaround**: Every API request must pass through the `apiClient` wrapper, which dynamically prepends the correct absolute backend base URL (e.g. `https://thaiba-garden-media-manager.vercel.app`).
* **Linter Rule**: The ESLint custom rule `no-restricted-syntax` bans all direct `/api/` string and template literals.
* **Workaround Syntax**: To pass the static linter check without string concatenation obfuscation:
  * Import `API_BASE` from `@/lib/api-utils` (defined as `'/api'` without a trailing slash, which does not trigger the literal matcher).
  * Use template literals: `apiClient(`${API_BASE}/endpoint`)` or `apiClient(`${API_BASE}/endpoint/${id}`)`

### 🔑 Access Token Refresh (Direct REST APIs)
* **Context**: Direct REST endpoints called via `http` or `dio` in mobile (e.g. offline sync, chat, upload) read `accessToken` directly from `currentSession` without checking for expiration. Since these bypass the Supabase client wrapper, they fail with `401/403` once the token expires (typically after 1 hour).
* **Workaround**: Future modifications must route requests through a token refresh wrapper that calls `await Supabase.instance.client.auth.refreshSession()` if the current session is expired.

### 🏢 Cross-Tenant RLS Leak in Presence Log Migrations
* **Context**: Policies in `supabase/migrations/20260615_presence_verification.sql` for tables `presence_logs` and `field_work_sessions` allow any authenticated manager/admin to read and write records, checking role only.
* **Vulnerability**: Managers/admins in Organization A can query or modify presence data for employees in Organization B.
* **Workaround**: Policies must be updated in a future database migration to check that the manager's/admin's `tenant_id` matches the tenant of the log owner.
